# Metodika

Кастомная тема WordPress: шапка и hero-блок на главной.

## Требования

- WordPress 6.7+
- PHP 8.1+

Поля админки — Carbon Fields, библиотека лежит в `vendor/` (ставится Composer’ом). Если `vendor/` нет:

```bash
cd wp-content/themes/metodika
composer install --no-dev
```

## Как поставить

1. Скопируйте папку `metodika` в `wp-content/themes/`.
2. В админке: **Внешний вид → Темы → Metodika → Активировать**.
3. Логотип: **Внешний вид → Настроить → Свойства сайта → Логотип**.
4. Тексты и картинка hero: пункт меню **Главная** в админке.
5. Меню шапки: **Внешний вид → Меню** (локация появится вместе с вёрсткой шапки).
