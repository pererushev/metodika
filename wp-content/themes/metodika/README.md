# Metodika

Кастомная тема WordPress: шапка и hero-блок на главной.

## Требования

- WordPress 6.7+
- PHP 8.1+

## Как поставить

1. Скопируйте папку `metodika` в `wp-content/themes/`.
2. В админке: **Внешний вид → Темы → Metodika → Активировать**.
3. Создайте меню (**Внешний вид → Меню**) и назначьте его в локацию шапки.
4. На главной заполните поля hero (заголовок, кнопка, картинка) в редакторе страницы.

Вёрстка и поля админки подключаются в ветке `feature/header-hero`, не в `main`.
